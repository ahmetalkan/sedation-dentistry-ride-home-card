# Who drives you home after sedation dentistry: a planning card

A ride-home planning card for sedation dentistry, with ADA, MedlinePlus and ASA sedation sources.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://sedation-dentistry-ride-home-card.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/sedation-dentistry-ride-home-card/`

It cites public pages on [qsedationdentistry.com](https://qsedationdentistry.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
